     РЕФЕРАТ

     РАСПРЕДЕЛЁННАЯ СИСТЕМА, IOT, APACHE KAFKA, KOTLIN, EVENT SOURCING, POSTGRESQL, DOCKER
     Объектом работы является распределённая асинхронная система обработки IoT-событий для мониторинга параметров среды и управления состоянием помещений.
     Цель работы — проектирование и реализация распределённой асинхронной системы обработки IoT-событий, обеспечивающей мониторинг параметров среды и управление состоянием помещений.
     В работе рассматривается построение системы на языке Kotlin с использованием Apache Kafka в качестве брокера сообщений. Система принимает события от датчиков, вычисляет состояние помещений по модели Event Sourcing, обнаруживает аномалии и предоставляет REST API для чтения данных. Все компоненты контейнеризированы с помощью Docker Compose.
     Результатом работы является функционирующий прототип распределённой системы обработки IoT-событий, развёрнутый в контейнерах Docker, с подтверждёнными результатами функционального и нагрузочного тестирования.




     ABSTRACT
     The paper focuses on the design and implementation of a distributed asynchronous IoT event processing system for environmental monitoring and room state management.
     The system is built with Kotlin and Apache Kafka as the message broker. It receives sensor events, computes room state using the Event Sourcing model, detects anomalies, and exposes a REST API for querying state and history. All components are containerised with Docker Compose.
     The result is a working distributed IoT event processing prototype deployed in Docker containers, validated by functional and load tests.

     ВВЕДЕНИЕ
     Рост числа IoT-устройств на производственных и коммерческих объектах создаёт потребность в системах, способных принимать и обрабатывать поток событий от сотен датчиков в реальном времени. Типовые задачи — контроль температуры, влажности, задымлённости, освещённости и состояния оборудования в офисных, складских и промышленных помещениях.
     Существующие решения — централизованные SCADA-системы и облачные платформы (AWS IoT Core, Azure IoT Hub) — либо привязаны к конкретному вендору, либо требуют значительных ресурсов для развёртывания. Большинство из них работают в синхронном режиме, что ограничивает пропускную способность при одновременном срабатывании множества датчиков или при восстановлении соединения после сбоя.
     Настоящая работа посвящена проектированию и реализации распределённой асинхронной системы обработки IoT-событий, обеспечивающей мониторинг параметров среды и управление состоянием помещений. Система построена на языке Kotlin с использованием Apache Kafka в качестве брокера сообщений, что позволяет гарантировать упорядоченную доставку событий, горизонтальную масштабируемость и возможность воспроизведения полного лога для пересчёта состояния.
     Структура работы включает четыре основных раздела. Первый раздел посвящён обзору предметной области и существующих решений. Второй раздел — проектированию архитектуры системы. Третий раздел — реализации и тестированию. Четвёртый раздел содержит материал по безопасности жизнедеятельности.
